    My generated map looks like this! (Clustered modules)

    Solution

    Likely your Tile Module Edge Size defined in your AreaOptionsSO asset does not match the module prefabs you are using.

    My props aren't being placed

    Solutions

    1. Missing component?

    Ensure there is a Prop Placement component attached to the same GameObject as your MoraMapGen component.

    2. Density too low?

    Check all of your Prop Density Multipliers and make sure none are set too low. Check these locations and set them to 1 as a test:

    • On the Prop Placement component.
    • On the AreaOptionsSO asset.
    • On each of your AreaDefinitionSO assets.

    Also make sure that you don't have any Prop Channel Density Multipliers set to 0 or a very low value.

    3. Too much collider overlap?

    Check your prop prefab's pivot. If the pivot of the prefab is inside a collider, it is likely failing to place due to overlapping other colliders.

    This is bad. It will almost always fail due to colliding with the world, assuming your modules have colliders:

    By making sure the pivot is where you would expect the floor or wall to be (or whatever the prop will be attached to), it will be much less likely to collide with anything.

    Consider adding Prop Anchor Overrides to your prop prefabs to specify where a prop should line up with a prop spot.

    See Prop Placement for more info.

    BakedMap

    When a map is generated, it is then stored as a BakedMap object that you can access at runtime to do things like query what room a player is in, check whether a location is inside a certain area, and use graph-traversal helpers to find the shortest path between two points or find the farthest position from a location.

    Accessing the BakedMap

    With a reference to your MoraMapGen component, you can access the BakedMap via MoraMapGen.BakedMap. That is the current baked map. It is null before a successful map generation or after clearing the map.

    You can add a listener to OnBakedMapReady to get the newly created BakedMap whenever a map is generated.

    using MoraGames.MapGen;
using UnityEngine;

public class BakedMapExample : MonoBehaviour
{
    [SerializeField] private MoraMapGen _mapGenerator;

    void OnEnable()
    {
        _mapGenerator.OnBakedMapReady.AddListener(HandleMapBaked);
    }

    void OnDisable()
    {
        _mapGenerator.OnBakedMapReady.RemoveListener(HandleMapBaked);
    }

    private void HandleMapBaked(BakedMap bakedMap)
    {
        int numRooms = bakedMap.Rooms.Count;
        int numCorridors = bakedMap.Corridors.Count;
        Vector2Int dimensions = bakedMap.GridDimensions;
        
        Debug.Log($"Generated {numRooms} rooms and {numCorridors} corridors. Map dimensions: {dimensions}");
    }
}

    If you need to get a reference to an already generated map (whether because it was generated in editor, or at a previous moment at runtime) use MoraMapGen.BakedMap to access the BakedMap. Regeneration or ClearMap invalidates the previous BakedMap, so be careful about caching a reference to it. You can check if the map has been baked with MoraMapGen.IsMapBaked.

    Usage

    See the API documentation for BakedMap for the complete interface.

    The BakedMap provides lists of BakedArea for all of it's rooms and corridors via BakedMap.Rooms and BakedMap.Corridors. It also has lots of helper methods for finding specific areas, areas that match a certain criteria, etc.

    See also Graph Traversal for getting areas by distance and connections.

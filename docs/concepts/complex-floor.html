    Complex Floor

    A Complex Floor is a Corridor path floor that handles each possible placement differently, rather than simply placing the same prefab no matter where.

    A Complex Floor component can be added to a prefab to be used as a Floor B module in your TileModuleDefinitionSO assets.

    Note

    Complex Floors are only intended for use in Corridors.

    It lets you specify sub-prefabs to use whenever the Floor module is placed in one of the following places:

    Straight

    Corner

    T Intersection

    X Intersection

    Setup

    1. Add ComplexFloor to the root GameObject of your Floor module prefab. The module-spawning code looks for the component on the instantiated prefab root.
    2. Assign a prefab to each of the five fields in the ComplexFloor Inspector:

    1. Assign the module prefab to Floor B in your Tile Module Definitions asset.

    Note

    A Complex Floor will only work as Floor B, since that is the module that is used for Corridor paths and Room entrances.

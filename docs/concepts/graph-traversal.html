    Graph Traversal

    A baked map layout can be viewed as two related graphs:

    • Grid-space graph: each tile or cell is a node, connected orthagonally to it's neighbors that can be reached from it. Walls block connection between neighboring tiles.
    • Area graph: each area (room or corridor) is a node. Areas are linked when they share connecting grid spaces. (Eg. A room is considered connected to a corridor when it has a door leading to it.)

    See the API documentation for the various related extension methods for complete info:

    • BakedAreaGraphExtensions
    • BakedMapGraphExtensions
    • BakedMapPathExtensions

    Grid-space Graph Traversal

    With a reference to a BakedMap you can use the following extension methods:

    • BakedMap.GetFarthestGridSpaces gets a list of BakedGridSpace that are the farthest away from the reference BakedGridSpace and returns the distance in steps.

    • BakedMap.PickFarthestGridSpace randomly picks a BakedGridSpace from those tied for farthest returned by GetFarthestGridSpaces.

    • BakedMap.GetFarthestAreasByGridDistance gets a list of BakedArea that are the farthest from the reference area and returns their distance in grid steps.

    • BakedMap.PickFarthestAreaByGridDistance randomly picks one of the areas tied for farthest by grid-space distance returned from GetFarthestAreasByGridDistance.

    • BakedMap.GetGridDistanceBetweenAreas returns the number of grid steps from one area to another.

    • BakedMap.GetGridDistancesFromArea gets a dictionary of the distance in connected grid steps from a specified BakedArea to every other BakedGridSpace.

    • BakedMap.GetGridDistancesFromSpace gets a dictionary of the distance in connected grid steps from a specified BakedGridSpace to every other BakedGridSpace.

    • BakedMap.TryGetGridPathBetweenAreas gets the shortest walkable path of BakedGridSpace between the two specified BakedArea.

    • BakedMap.Find2FarthestGridSpaces finds the two grid spaces that are the farthest apart in the entire map.

    • BakedMap.TryGetGridSpacePath gets the shortest walkable path of BakedGridSpace between the two specified grid positions (Vector2Int or BakedGridSpace).

    • BakedMap.GetGridDistance gets the distance in grid steps between the two specified BakedGridSpace.

    Area Graph Traversal

    With a reference to a specific BakedArea you can use the following extension methods:

    • BakedArea.GetImmediateGraphConnections gets all of the rooms and corridors that are connected to this one.

    • BakedArea.GetFarthestAreas gets a list of the farthest area(s) from this area and returns the distance in steps.

    • BakedArea.PickFarthestArea randomly picks one of the tied farthest areas returned from GetFarthestAreas.

    • BakedArea.TryGetGraphToArea gets the graph of connecting areas between two areas in the form of a sequential list of BakedArea one would need to traverse to get from area A to area B.

    • BakedArea.GetGraphDistanceToArea returns an int representing the number of steps it takes to get from this area to a specified area. Each step is an area connection, not a grid space.

    • BakedArea.GetGraphDistancesFromArea gets a dictionary of the distance in area connections to every other area from this area.

    With a reference to the BakedMap you can use the following extension methods:

    • Find2FarthestAreas finds the two areas that are farthest apart in the entire map.

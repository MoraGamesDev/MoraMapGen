    Generation Options

    "Generate Map" Button

    Generates a map in the editor based on your settings. This will clear any existing map first.

    "X" Clear Map Button

    Deletes the existing map and clears all baked data.

    "Generate On Awake" Toggle

    When turned on, the map will generate at runtime on Awake(). If there is already a map, it will clear it first.

    Generation Source

    Select between two different methods for determining the layout of the map.

    Procedural

    The default mode. Uses wave-function-collapse (WFC) to randomly generate a map layout using your settings.

    Tilemap

    Uses a Unity Tilemap as the layout, so no generation occurs, but it still uses your random seed and Area Options settings to define the areas and place GameObject. See Generating from a Tilemap

    Tilemap Baking

    After you've generated a map, you have the option to bake the layout to a Tilemap. Using Unity's Tilemap editing features you can modify the layout and then us it as the Generation Source.

    Destination Tilemap

    The Tilemap to bake the generated layout to.

    "Bake to Tilemap" Button

    Bakes the layout to the destination Tilemap. Button is disabled if there is no assigned destination Tilemap.

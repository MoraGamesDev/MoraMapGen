    Class MapGameObjectPlacement

    A IMapGenPostProcess that lets you specify where to place arbitrary quantities of prefabs when the map is generated.

    public class MapGameObjectPlacement : MonoBehaviour, IMapGenPostProcess
    Remarks

    Attach this component to the same GameObject as your MoraMapGen component. After the map is baked, it selects areas and positions according to its placement settings and instantiates the configured prefabs there. Placed objects are tracked so they can be removed when the map is cleared.

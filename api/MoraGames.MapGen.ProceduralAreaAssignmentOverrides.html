    Class ProceduralAreaAssignmentOverrides

    Allows you to assign AreaDefinitions to rooms and corridors before the normal map gen process assigns them randomly. You can specify areas by criteria such as size, door count, or distance from another area.

    Remarks

    Attach this component to the same GameObject as your MoraMapGen component. Overrides are evaluated in list order, and each one only considers areas that have not been assigned yet.

    Rooms and corridors are evaluated together, so an override can reference an area definition assigned by an earlier override in this list (of either type) or by an earlier override component.

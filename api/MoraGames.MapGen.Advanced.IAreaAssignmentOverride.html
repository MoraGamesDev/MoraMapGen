    Interface IAreaAssignmentOverride

    Implement on a component attached to the MoraMapGen GameObject to override which AreaDefinitions are assigned to which areas.

    Namespace: MoraGames.MapGen.Advanced
    Assembly: MoraMapGen.Runtime.dll
    Syntax
    public interface IAreaAssignmentOverride
    Remarks

    Overrides run once per generation, before required, optional, and generic areas are assigned. Multiple override components are evaluated in component order. Each one only receives areas that are still unassigned, and assignments from earlier components are already applied (e.g. visible via GenMap.GetAllAreasByDefinition).
